# 找轮子

只负责成熟实现的查找与采用，训练、文档处理和接口规范沿用所属技能，不复制其流程。

1. **先查已有选择。** 现有实现满足本轮任务、许可和预算就直接复用，返回领域流程；不重新联网选型、填对照表或申请批准。版本、输入或约束改变时，只复核受影响部分。
2. **有缺口才找候选。** 明确输入→输出与缺口，核对官方包/仓库/文档，比较适配、维护、许可和成本；给出有效备选及建议，新核心路线交用户选择。未选定可继续已授权的小样本验证，不擅自切主栈、下载大资产或扩大成本。
3. **选定后用原生接口。** SDK/CLI够用就直接调用；确需适配时只补缺口，记录精确版本、许可、来源、改动与真实验证。成熟不等于无错，未验能力如实标记。明确授权的算法创新仍可开发新模块，其余工程复用上游。

仅有新选型或接入问题时读[按需分工](references/reuse-workflow.md)；[对照表](assets/options.template.md)和[来源模板](assets/upstream.template.json)按需用，已有项目记录足够则不另建。
