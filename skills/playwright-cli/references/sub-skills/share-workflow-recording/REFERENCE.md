# 浏览器录像

| 目标 | 读取 |
|---|---|
| 录制网页操作、用户旅程、E2E 验收证据 | [工作流录像](workflow-evidence.md)，按目标行为核验 |
| 演示视频需要字幕、配音、剪辑或画面审阅 | 另用视频后期工具（演示后期技能 `share-enhanced-screen-recording`（可选，本包未包含）） |
| 普通视频生成、已有非浏览器素材剪辑 | 视频制作技能 `video-production`（可选，本包未包含） |

先复用项目已有录像脚本和真实服务。录制原片与后期版本分开保存；普通录像不自动加入配音、付费生成或外援审查。
AI 消息/回复/工具链四类审计只用于采用该协议的 AI 产品，普通网页按 DOM、网络与实际用户行为验证。录像不能替代相关测试，也不能以画面成功证明后台任务完成。
