# 控制重建成本

默认经济档：一次完整预览，最多一轮修正。脚本先检查对象清单、文字覆盖、页数、越界、图片比例和线段数量；AI只读通过/失败摘要及失败对象ID，详细日志保留文件。首次检查整页，此后只看问题区域和其附近连接关系。纯装饰差异不触发整页重做。

漏正文、断开语义连接、文件打不开仍是交付缺陷；达到轮数上限就报告具体缺陷，不能冒充通过。用户明确要求继续精修时才增加预算。已有确认的文字与坐标优先复用，只对模糊区域做OCR；不反复读取全量OCR。

不以像素相似度强迫增加轮数；不默认引入整页去字背景、重型分割模型或整套应用。缺少原图对象清单时，脚本无法凭空发现语义漏线：仍需一次原图对照。对象齐全也不代表裁剪内容正确，裁剪边缘须目视检查。
