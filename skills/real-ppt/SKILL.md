# 真实PPT：原生可编辑 PowerPoint

“真实PPT”指交付可打开、可继续编辑的 `.pptx`。优先让标题、正文、箭头、框线、表格和普通图表成为 PowerPoint 原生对象；真实照片、显微图、复杂数据图保留为图像素材，并把标注、说明和图例做成可编辑对象。

## 与图片PPT分流

用户指定“生成PPT图片”“PPT生图”时先读 `~/.claude/skills/pptx-gen/SKILL.md`；不能仅因要交付 `.pptx`、要备注或当前缺生图工具就改成本技能。明确要求在PPT里绘制可编辑元素，才属于本技能的绘图。

| 用户意图 | 路由 |
|---|---|
| “图片PPT”：每页是一张 AI 生成的完整画面 | `pptx-gen` |
| “真实PPT”：可编辑文字/形状/图表，套模板、改已有 `.pptx` | 本技能；已有文件操作细则见 Office 工具技能 `share-office-tools`（可选，本包未包含） |
| 图片、截图或论文图重建成可编辑形状 | 本技能按原图复刻文字和简单几何；专门的图片转形状流程属 `share-office-tools`（可选，本包未包含） |
| 论文级统计图、显微图或精确科研可视化 | 先用代码（如科研绘图技能 `share-sci-plot`（可选，本包未包含））生成准确图，再作为素材放入真实PPT |

不要把每页扁平化为整页图片冒充可编辑稿。用户若要求整页生图，转 `pptx-gen`；若要求从图片重建，保留照片级内容作为图片，重建文字和简单几何为原生对象。

图片PPT同时交付原图页和可编辑页时，遵循 `~/.claude/skills/pptx-gen/references/paired-editable-delivery.md`；纯可编辑任务不自动增加图片页。没有本地Office时可直接用成熟写入库创建原生对象，不必附加未执行的宏。

## 工作模式

- **新建**：先确定听众、汇报目的、时间和主结论；写逐页提纲，再用 PptxGenJS 生成 PPTX。输出同时保留 `.js` 源码和必要素材。
- **模板复用**：先检查模板版式和渲染效果；按其页面比例、字体、颜色和布局填充内容，保留模板风格。逐页检查字体替换和遗留占位符。
- **修改旧稿**：先复制到任务目录，保留原稿；检查全稿与备注，按要求编辑副本，不静默改写原件。
- **科研汇报**：每页表达一个可口述的要点，标题写结论；数字回到来源表或结果文件核对。简单柱线图优先原生图表；显微图和复杂科研图保留准确的原始图像，增加可编辑标注。

## 每次交付前

渲染每一页并检查完整缩略图和重点页，修正文字溢出、遮挡、对齐、图像裁切、字体替换和占位符。本机 LibreOffice 渲染不等于作者的 PowerPoint，小形状里的文字和符号最容易偏移：渲染前先查字体，看到偏移先查 XML 再下结论（见 `references/authoring-and-qa.md`「服务器渲染和 PowerPoint 不一致」）。运行越界检查；结构密集的稿件额外检查边界和重叠。检查页序、文字、图表和备注，再交付 `.pptx`、源码及必需素材。具体命令、模板处理与环境降级见 `references/authoring-and-qa.md`。
