# 真实PPT制作、模板与验收

## 新建可编辑稿

使用 Node.js 的 PptxGenJS 写 `.js` 源文件，并设置明确的 16:9（或与来源稿一致）页面尺寸、主题字体、配色与边距。文字、标题、简单图形、箭头、表格和常见柱线图用原生 PowerPoint 对象；需要精确外观的科研图从数据代码绘成 SVG/PNG 后嵌入。交付 `.pptx` 和源 `.js`，不要只留生成后的二进制稿。

开始前先看本机是否已有 `pptxgenjs`、LibreOffice/soffice 和渲染工具；缺工具时先用已有 Office 技能支持的路径完成可读写部分，并如实报告缺少的视觉验收步骤，不安装全局依赖。

## 模板与已有幻灯片

1. 先渲染模板或原稿每一页，查看缩略图；提取页面比例、颜色、字体、常用版式和页脚。
2. 先建立总提纲，映射到已有页面角色；不同内容选合适布局，不把所有页面套成同一文字框。
3. 保留源稿。针对已有 `.pptx` 的局部编辑先备份原稿（专门的 Office 操作技能 `share-office-tools`（可选，本包未包含））；需要重建或扩展原生可编辑稿时另存输出文件。
4. 若模板结构复杂、无法稳定复制占位元素，先试选取已有布局或复制兼容页面；不要手工猜 XML shape 索引、不要未验证地全局替换压缩包 XML。

## 视觉素材与科学真实性

- 对每张结果图记录数据文件或论文来源；把数据图简化到投影距离仍能读的字号和标记。
- AI 生成图可做封面、背景或概念插图；不得让图像模型绘制或篡改实验图、坐标、曲线、比例尺和定量结果。
- 原始电镜照片、显微照片、3D 原子图等保留为图像；把箭头、圈选、标签、图例作为独立可编辑层。
- 图表如果是决定科学结论的结果图，不因“原生可编辑”而重算不同口径；使用已核验的图形素材，或从已核验结果表生成并交叉检查数字。

## 渲染与质量检查

优先调用上游 `slides` Skill 所列检查器（可用时）：

```bash
python3 scripts/render_slides.py deck.pptx --output_dir rendered
python3 scripts/create_montage.py --input_dir rendered --output_file montage.png
python3 scripts/slides_test.py deck.pptx
python3 scripts/detect_font.py deck.pptx --json
```

这些命令是工作模式示例，脚本目录取决于实际安装位置。若检查脚本不可用，用 LibreOffice 渲染成 PDF 后逐页转图并人工检查；在环境支持时同时解析 `.pptx` 内的文字，查缺页、乱码和 `TODO`/占位符。至少查看整稿缩略图，并放大检查含密集文字、复杂图表、图片裁切和来源脚注的页面。修正后只需重渲染修改页，再做一次完整串页检查。

交付前简述：`.pptx` 与 `.js` 路径、关键素材、哪些图层仍是图片，以及渲染/溢出检查是否通过。没有运行的检查不能写成通过。

### 服务器渲染和 PowerPoint 不一致

本机用 LibreOffice 渲染，作者用 PowerPoint 看，同一个文件两边可能排得不一样。最常见的是小形状里的符号或文字偏离中心，其次是换行位置不同。原因有三：
- 字体缺失被替换后，字形的上升、下降高度和字宽都变了；
- 东亚字体为空或缺失时，LibreOffice 会借别的 CJK 字体来算行高；
- 自动调整大小、默认内边距和顶端锚定，两边的处理也不完全相同。

交给期刊或作者的 PDF/PNG 往往就是服务器渲染出来的，偏移会原样带进去。所以：

- **渲染前查字体。** 列出文件用到的全部字体，包括主题的 latin/ea/cs 字体和各段文字显式指定的字体，用 `fc-match` 逐个查本机实际会用哪个。缺的字体装度量兼容的替代品到 `~/.local/share/fonts`：Arial→Liberation Sans，Times New Roman→msttcorefonts 或 Liberation Serif，Calibri→Carlito，Cambria→Caladea。找不到兼容字体的，交付时写明。
- **渲染后查回退字形。** 用 PyMuPDF 列出实际字体和声明字体不一致的字形，放大检查这些位置，以及每一处"形状上叠着文字"的地方。
- **看到偏移先查 XML，再下结论。** 核对文本框和宿主形状的中心是否对齐，以及锚点、内边距、自动调整和字体。如果设计上本来居中、只是渲染偏了，就按渲染问题处理，不当成作者的设计缺陷去报。
- **修的时候用两边都稳的写法。** 把符号写进宿主形状本身：水平居中、垂直居中锚定、内边距为 0、显式字体，不另叠文本框。
- **说明交付件是怎么渲染的。** 最终交付图以作者用 PowerPoint 导出的 PDF 为准最稳。交付服务器渲染版时注明"LibreOffice 渲染"，并把检查过的关键位置列出来。
