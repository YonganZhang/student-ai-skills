# CLI 设计合同

## 先确定契约，后选框架

记录谁调用、最短正常调用、真源、状态变化、失败行为和可验证结果。对已有 CLI，先读 README、help 和实际消费者；保留已发布参数、机器输出和退出码，必要变更显式版本化。不把项目 CLI 自动变成全局命令。

适合 CLI：重复操作或共享状态，需要稳定参数、校验和脚本调用。一次性任务、偶尔改一次的文件、官方工具已覆盖的场景，先直接用现有能力。CLI、SDK、HTTP 和 MCP 按消费者选择；不能仅凭“说明占 token”排除适合的接口。

## 基本契约

| 项 | 新工具默认 | 边界 |
|---|---|---|
| 帮助 | `--help` 短速查，子命令有例子 | 既有 `help` 可保留；复杂命令分层，不为一屏删必要语义 |
| 文档 | 所属仓库 README 或链接到 CLI 专页 | 用途、安装、例子、输出、退出码、状态变化、验证；认证存在时说明来源，不放密钥 |
| 展示 | 默认短文字，诊断 stderr | 二进制/下载工具保留原生流；长结果按任务设 limit、分页或导出 |
| 机器接口 | 需要程序消费时提供稳定格式，如 `--json` | 不把日志混入 stdout；规定成功/错误/部分失败的通道和字段；可用 JSONL/已有协议 |
| 退出码 | 0 成功，1 运行或业务失败，2 用法错误 | 环境、权限、网络失败归 1；部分失败默认非 0，用户显式允许的部分成功须有结果字段；沿用已有接口 |
| 交互 | 自动化可不读终端、不询问 | 缺必要参数直接报错；人用交互模式可显式开启；子进程 stdin 按任务接数据或 DEVNULL |
| 依赖 | 复用现有/标准库，必要才加框架 | 项目 venv/conda；不因小 CLI 新设发布链、数据库或常驻服务 |

机器错误可以是约定的 JSON，也可以 stdout 为空、stderr 文本加非 0 退出码；选一套并写清，不让消费者猜。母模板采用后者。无参数的状态查询可以有默认动作，不能默认执行有影响的写操作。

## 写入与并发（仅写 CLI 需要）

- 复用现有文件、SQLite、数据库或 API 作为真源；CLI 是接口，不另起一份同步状态。全局禁止数据库不成立。
- 同目录临时文件加原子替换可以避免半写文件，**不能单独防止覆盖别的写者**。先比哈希再替换存在检查与写之间的竞争。
- 多写者文件操作：共享同一把锁，锁内重读 → 验证版本/哈希 → 修改 → 原子替换。所有写者都必须遵守同一锁，外部手改不受它保护。崩溃持久性有要求时再考虑 fsync。
- 数据库操作：用事务与条件更新（如版本字段 WHERE 条件），检查影响行数。远端状态使用服务已有版本/ETag 与冲突响应，不伪造本地 CAS。
- 批量删除、不可逆或影响外部状态的操作先给可核对预览；应用方式按既有契约，新工具本地用 `--apply`，外发用 `--yes`。这两者都是运行意图，不替代授权、锁或幂等设计。
- 在已授权范围内，普通可撤销、小范围写操作可以直接执行；跨项目写入解析出精确目标，歧义拒绝。只给读取引入合理的模糊匹配。
- 写结果回显具体目标和实际完成状态，异步返回 accepted/job ID 不能叫 completed。需要外部回执时回读；远端调用有超时，有界重试按幂等性与任务决定。

## 条件能力，不是默认架构

- 固定位置的多项目状态：可以向上定位项目根，接受路径/编号；worktree 关系必须遵循该业务真源，不能所有副本都自动归主体。
- 长结果：先默认返回够决策的小结果，详情/limit/分页另取；测到必要再优化 token。`--json` 并不必然比文本或源文件更短。
- 日志与网络：stderr 日志、超时、清晰错误；凭证用已有安全配置，避免参数/URL/日志泄露。失败不无限重试，也不把空输出当成功。
- 老接口：在真实消费者上验证兼容。展示文字无程序消费者时可以改善；不要要求所有新旧文本逐字一致。
- 短入口：重复调用确有需要时在 PATH 安装包装入口，源码仍在所属仓库。复制母模板后业务代码归项目，不链接回模板运行。
- 发现性：项目 README 或业务 skill 索引通常足够。只有像 `plan` 这样每轮都需要的入口才考虑常驻规则/hook；没有常驻提示不等于交付失败。

## 验收按风险选择

只读工具至少验证正常查询、缺参数/非法选项、缺目标/真实失败、无交互等待，以及机器消费者约定。文档例子要实际运行；stderr/stdout 与退出码一致。

写工具另验实际写后回读、拒绝路径无变化；有多写者才验并发竞争；有预览才验预览不写；有异步任务才验 accepted/completed；有兼容承诺才验旧消费者。测试公共行为，不机械要求每个 verb 同样数量的测试。
