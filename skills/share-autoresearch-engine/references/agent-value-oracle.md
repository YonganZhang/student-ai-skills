# Agent 职责、可达收益与可学习性验证

唯一方法真源；供科研优化、组件集成和 Agent 设计入口按需引用。这里的 Agent 可以是纠错支路、门控器、模型路由、检索/工具选择、序列策略，也可以是提出或挑选改动方案的 LLM 设计团队，不要求一定采用大语言模型。

## 何时用，何时不用

当要给 Agent 分配决策职责、投入训练/提示词优化、比较不同 Agent 组织形式（单体/多角色/自审），或其增益很小且原因不清时使用。先回答：这件事值得做吗？在允许的动作里全选对能改善多少？实际可用输入能支持学会吗？

普通接口错误、依赖安装、确定性代码修复直接处理，不为其强制做 oracle。没有可靠标签/模拟器/终局验证器时，先明确评价缺口并做可验证的小范围实验；不要编造理想决策标签。解释概念时只讨论，不自动启动实验。

## 默认顺序：先空间、再答案表、最后定量

用指标证明某个 Agent 设计有价值时，按下面顺序推进；不要一上来用端到端训练加多随机种子比较各种 Agent 配置。

1. **先找明显效应。** 用单次运行（一个 seed）筛查；真正的提升应远大于已知的 seed 噪声底，一次就看得出。筛查阶段看不出的差别，不靠加 seed、加会话数把它“做显著”。多 seed 只用于给已经明显的效应定量（幅度与稳定性，接稳定冠军协议）。为什么：小差异加 seed 只会得到“统计上略显著、实际不可用”的结论，且每轮都要重付训练成本。
2. **先算理论空间，要求显著。** 固定动作/候选集合，按第 2 节求“全部选对”能得多少，并与不动作、随机选、一轮单体这类简单策略比。空间只比噪声底大一点时，不投入提示词、角色或记忆优化；改动作空间、候选来源或任务定义。
3. **固定接口，建答案表。** 把“这些输入 → 最佳/可接受决策”连同实测效用冻结成答案表（第 4 节的监督格式）。之后每次改提示词、角色分工、给哪些数据、给几轮思考，都在同一答案表上查表打分（选中最佳的比例、后悔值、排序一致性），不重新训练。提示词和数据暴露本身是被选择的超参：答案表按独立单位划分调参部分与留出部分，只在留出部分报告结论。
4. **最后端到端确认。** 只有在答案表留出部分明显缩小了 oracle gap 的配置，才进入新数据/新 seed 的端到端复核，这时才用多 seed 定量。

边界：答案表只能来自开发/验证标签或可执行动作的实测结果，不碰封存测试；它衡量“在给定候选里选得对不对”，不衡量“能否生成新候选”，后者要另建生成任务的评价。无法建立答案表时，先说明评价缺口，不用端到端噪声实验代替。

> 示例：一个 LLM 设计团队与单体做了三轮端到端对照（每组 4 次设计 × 4 个 seed），三轮都没测出团队价值，因为各方案真实效应只有 2–3 点、与 seed 噪声同量级，而团队与单体的差别淹没在其中。改为先用已实测的候选方案建答案表，再比较谁更接近最佳选择。

## 固定不变量

- 原系统、版本/seed、输入处理、原生评价器/聚合、动作接口和成本预算显式绑定。逐 cell 配置不能从第一个样本或 seed 推广。
- 保留“不动作/原系统”候选，先做自比较及最小接口测试；候选越界或 OFF 不等价先修契约。
- 理想选择只能采用约定的可执行动作。不能直接拷贝真值重画输出，也不能给 oracle 无限调用/重试预算后与有限预算 baseline 比较。
- 标签可用于离线诊断和训练监督，部署策略只能使用当时可观察的信息。提示词不是标签可达性的替代品。
- 指标按完整终局重新评价；局部收益只有证明可分解后才能相加。
- 区分决策正确、动作有效和净收益。错误区域标签不自动等于“采用当前修正会获益”。

## 1. 写清职责和价值合同

记录：观察 O、动作集合 A、作用对象/时序、保持不变的部分、评价 J、成本 C、预算 B、baseline，以及期望的实际改善幅度。成本可作为预算约束或公开的效用项；多目标不适合压成一数时同时报告，不事后改权重。

分别问：错误来自主模型、候选动作、决策排序还是评价契约？Agent 是否能操作主要错误类型？例如只能选择已有候选就不能补出候选集中缺失的答案；只能编辑前景的系统不能在背景新增目标。

不先假定现有动作设计有价值。若要比较“保留/采用已有修正”与“删除/新增/移动”，应分成不同动作空间实验；不能把后者的上限冒充前者的潜力。

## 2. 先做理想决策实验

冻结实际候选输出或可复跑环境。在预算内，利用离线参考答案寻找 J 最好的动作组合，重新计算全流程输出和原定指标。记录选择、状态/输出、成本、收益与失败例，而不只给一个总分。

结果必须使用正确名称：

| 实际求得的东西 | 能说什么 |
|---|---|
| 有限动作全枚举或经过证明的精确求解 | 该数据、动作空间和目标下的精确最优 |
| 贪心、启发式或有限搜索找到的可执行方案 | 可行最好结果，是最大化问题最优值的下界；不是收益上限 |
| 经证明的松弛或理论界限 | 上界；注明松弛哪些条件及是否过松 |
| 使用未来信息/事后随机结果挑动作 | 信息放宽的诊断参照，通常不可由在线策略实现 |
| 直接按标签输出完整答案 | 真值参考；不能证明给定 Agent 的可达能力 |

小规模先精确求解以校验搜索；规模大时尽量同时给可行结果和上界。只有低的有效上界，才支持“该动作空间收益有限”；一次搜索没找到改善，不证明没有改善。若无法证明最优，明确仍有多少未知。

对于非可加指标（如原子匹配、集合覆盖、排序、多步状态），联合执行后重评。不能把各域独立好动作拼起来就宣称全局最优；共享预算也会破坏逐样本选择的独立性。

随机/连续决策需要单独处理：从相同初始条件复跑动作带来的新状态，考察终局和预期收益，不将旧日志里未执行动作的结果当已知事实。不要只看即时奖励，不把知道未来随机数的 clairvoyant oracle 当成因果策略可达的最优值；若其放宽条件确实包含原策略类，它可以是较松的上界，但未必可实现。无法重置/模拟时，说明反事实不可识别或依赖哪些假设。

## 3. 判断是否有价值、是否可学习

先看允许动作的可达收益是否足够、改善哪些错误、代价多大，以及是否只是损害在样本间转移。必须比较不动作、合理固定策略及简单同预算/同编辑量策略，不能只胜一个弱 baseline 就归因智能判断。

把三个缺口分开记录：

- **动作能力缺口**：即使选对也做不好，或动作不能处理主要错误；改职责/动作，而非盲目增强选择模型。
- **信息缺口**：最优决策依赖部署不可观察的变量；检查能否增加合法观察、允许查询或改成不确定性决策。
- **学习缺口**：已有信息包含信号、动作也有收益，但策略没学会；再优化监督、结构、训练或提示词。

用实际可观察输入做低成本预测探针，按真实独立分组留出数据，评估精确率/召回、决策后悔值和最终效用；稀有有害动作不能仅报 accuracy/AUC。输入相同而最优动作冲突、隐藏未来变量等是信息不足证据；一个简单分类器失败不证明所有模型都学不会。

理想策略用到了标签而实际 Agent 没有，这是两者的条件差异；因此大 oracle gap 只说明潜力，不保证可学习，更不保证高收益能迁移到未见数据。

## 4. 把有效动作变成监督

在训练部分保存决策样本：合法观察/历史、候选动作、动作后的终局效用和成本、相对不动作的增量、可接受动作集合、评估器版本及来源。

监督的是行动价值或有益决策，不只是原任务的真假标签。平分动作保留集合或偏好低成本/不动作，不强造唯一标签；近似搜索产生的是近似教师，不能标成真实全局最优。交互动作的标签要包含状态/其它选择背景，不能变成无条件逐点标签。

按接口选择动作分类、候选排序、价值回归、示范/偏好数据或序列策略学习。提示词适用于确有语言模型决策接口的情况；神经支路使用相应监督损失。先验证真实动作/梯度/执行链，再扩大训练。

只从训练部分构造训练标签/拟合统计；必要时用 out-of-fold 主模型预测减轻训练输出过度乐观。内部验证用于选择，最终留出集独立验收。若曾用某留出集标签诊断并据此改方案，它就不再是未触碰的最终检验集；记录用途并保留新的独立检验，不通过改名掩盖复用。

## 5. 对照、停止和交付

比较同条件 baseline、简单策略、实际 Agent、受限 oracle/界限；记录种子/切分、动作使用率、净收益、成本和受损子群。学习闭合了多少 oracle gap 仅在目标/动作/预算一致且分母有意义时报告；近零/负分母不报夸张比例。

- 有效上界很低：停止当前动作方向或重定义任务。
- 可行理想策略有显著收益，但信息不足：先解决观察条件。
- 信息有信号且理想策略值得学：用动作监督训练，再做原生多种子对照。
- 搜索/标签/评价不可靠：修诊断，不将不确定性包装成模型失败。
- 实际策略无法超过简单同预算策略：不宣称智能决策的额外价值。

最低交付是职责/动作合同、oracle结果及证明等级、信息与监督样本说明、继续/重设计/停止的证据。没有实施的实验写“待验证”，不把流程设计当成实验完成。本方法是低成本诊断工具，不是要求所有任务先走完整审批或写大报告。
