# 数据准备、评价与工程测试

沿父S2/S3/S4/S5/S8执行；下列是LLM接口，非新通用阶段定义。

## 数据链

只读原件与来源/用途/许可/敏感性登记→文本层提取或扫描OCR→保守规范化→质量/主题/语言/隐私核查→精确和近似重复候选复核→来源簇划分→任务监督构造→目标模板/token化→版本化配方。

- 保留页码/段落/表格依据、负号、单位、百分数与数学符号；不让模型猜补OCR丢失内容。主题/语言分数只是筛选信号，不是事实正确证明。
- 同文变体、专利家族、翻译/摘要/生成问答继承来源簇。fit用于学习，select用于所有选点，evaluate作独立开发确认，test冻结后开启；小数据按父合同定义独立层级，不静默重划已有冻结集合。
- CPT保留正文续写目标；SFT为messages或prompt/completion；偏好为chosen/rejected；奖励任务需可验证结果。QA答案与引用、隐私/版权均需实质核查，CSV的accepted字段本身不是证据。
- 使用模型自身tokenizer/chat template，明确system/user/assistant、EOS、thinking/final。检查截断、空监督、有效输入/目标token数；按目标只在正确位置算loss。不能直接把其他模型模板当通用模板。
- packing按原生实现验证边界、跨样本注意力和监督，不默认打开。文字长度不等于token预算；输入token、监督token、padding吞吐口径分别记录。

## 分层测试与停止条件

| 层次 | 应交证据 |
|---|---|
| 数据/标签/评分器 | 原件身份、split/簇/污染覆盖、正确/错误答案与错单位反例；格式和事实分别评分 |
| 模板与监督 | 实际编码、角色/EOS/mask、截断/空监督反例；不能只验证JSON可解析 |
| 流水线与更新 | 少量可学习任务、有限loss、optimizer成员、adapter梯度及权重变化；禁用/断梯度对照按父体检要求 |
| 硬件与恢复 | 实际精度、rank同步、显存/速度、严格checkpoint恢复，optimizer/scheduler/RNG不能省略后仍称可恢复 |
| 任务开发与回归 | 基座/微调相同证据与解码口径，格式/事实/单位/依据/缺失处理、通用遗忘、成本分开报 |
| 导出/量化/最终测试 | 依release子流程先开发选择，再冻结最终评价；未验分支写待验 |
| 服务 | parser/template/API、上下文/并发/延迟/显存、故障/回滚与漂移 |

先从能容纳目标模型的最小硬件测，不要求先单卡OOM；DDP复制模型，显存不自动合并。换卡数、目标模型、长度、量化或内核需重测受影响接口，不为普通小修改重跑全流程。

模型裁判先与人工/可验证规则校准，披露裁判偏差、版本和成本。仅有合成接口样题不能代替真实领域金标；未运行、权限不足、污染未覆盖项明确列出。test失败可报告，不用同一test反复调参后宣称独立通过。
