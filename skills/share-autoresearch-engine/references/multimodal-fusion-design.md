# 多源与多模态可训练融合

通用执行顺序以[端到端学习 SOP](end-to-end-learning-sop.md)为唯一真源；具体接线读[组件工作流](component-integration.md)。本页只补充融合接口选择。

| 已有信息结构 | 合理候选 | 必须辨别 |
|---|---|---|
| 同类型多传感器历史 | 共享时间编码＋源身份，拼接或跨变量注意力 | 联合输入已会学习，显式交互是否新增收益要实测 |
| 不同类型或不同长度序列 | 各源编码，query-key/value 交叉注意力 | 时间语义与 mask 对齐，不靠 reshape 假装同结构 |
| 静态属性＋历史＋已知未来量 | 静态条件、变量选择或独立分支 | 未来变量在起报时必须已知；标签派生量不可用 |
| 已知邻接或坐标关系 | 图/位置编码结合时序编码 | 关系必须有来源；同一住宅不等于共墙邻接 |
| 缺失目标历史 | 可见条件或可学习目标 query | 不能冒充有目标历史原模型复现；query 不创造缺失观测 |

保留源值、源身份、可用性与年龄，让网络端到端调整。Attention 是可训练结构，不保证注意力权重等于因果解释；多源信息可能冗余，梯度通也不等于有泛化收益。

最小效果比较是同输入、同编码器的简单拼接与 attention，加可信 incumbent。父分支独立模型、shuffle/错位、冻结编码等按假设择一，不强制每次都开全矩阵。masked-value 不变性与全缺失行为属于正确性检查；shuffle 后性能未降只能触发进一步诊断，不能单独判泄漏或断路。

融合模块疑似未起作用（gate 不动、attention 均匀、提升来源说不清、换挂接方式才变好）时，按需查[诊断菜单与失败模式目录](multimodal-fusion-diagnostics.md)。

领域经验见[地学融合约定](case-studies/geoscience-fusion-design.md)（另有室温多传感器案例，原始记录未随本包发布）。其数据、数值与领域硬约束不外推。
