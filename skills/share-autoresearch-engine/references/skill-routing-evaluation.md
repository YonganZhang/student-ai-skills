# 研究技能路由评测

正例和相邻近误触负例保存在 `../evals/evals.json`；入口、兼容入口和参考路径均应实际存在。变更路由时保留已有评测并增加用户真实意图与近似无关意图。

## 评测层次

1. **结构校验**：JSON格式、唯一ID、入口行数、Markdown路径、旧组件库文件与脚本无意外删除。运行 skill-creator 的文件名、路由、引用与孤儿审计；全局旧告警与本次新增问题分开。
2. **作者逐例判断**：逐条记录当前文本会进入哪个工作流、做什么、不该做什么及证据段落。该结果是可审阅的人工式规则判断，不是调用另一个模型的盲测，不报告虚构的召回率/准确率。
3. **行为验收**：在真实项目看最终有没有把模块接入统一消费者、实际反向更新、处理缺测并完成同输入实验；检索到代码、路由通过或训练跑通都不是效果提升证明。

只有实际另行调用评估模型/人工评审并保留输出时，才能报告独立触发评测。机器检查引用和文本存在只说明规范可读取，不证明未来助手一定遵守。
