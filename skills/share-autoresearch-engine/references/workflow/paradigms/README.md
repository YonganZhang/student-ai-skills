# 范式手册：同一套流程，按任务族换具体内容

[标准流程](../standard-flow.md)规定所有深度学习任务按 S1–S9 走、每一步交什么；本目录给出各任务族在这些阶段上的具体做法：数据接口怎么写、独立单位是什么、评价器怎么自检、先跑哪些基线、体检用什么反向对照、去哪里找现成实现。

## 读哪一份

| 任务的输出是什么 | 读 |
|---|---|
| 逐像素/体素的结果：点或中心坐标、分割掩膜、计数（原子柱、斑点、细胞、断层中的颗粒） | [vision-dense.md](vision-dense.md) |
| 一张图一个答案：类别、多标签、连续值、检索嵌入 | [vision-image.md](vision-image.md) |
| 未来若干步的序列、窗口 → 标量，或静态参数 → 轨迹 | [time-series.md](time-series.md) |
| 一行一个样本、各列含义不同（含由时序做出的滞后特征表） | [tabular.md](tabular.md) |

## 用法

- 每份文件结构相同：适用范围 → 数据接口合同 → 划分 → 指标与评价器 → 强基线 → 增强 → 体检 → 模块放置 → 调参起点 → 已验证经验 → 推荐库。只读当前阶段需要的那一节。
- 一个任务跨两类时（如图像特征进 GBDT、序列与静态属性联合），各读对应一份，再读[多模态融合](../../multimodal-fusion-design.md)决定融合接口。
- 这些文件只写任务族特有的内容。划分、选择、泄漏、调参、排错的通用规则在各自的参考文件里，范式文件只链接。
- 填写[项目合同](../project-contract.md)时，以选中范式的第 2–4 节为提纲写项目事实（坐标约定、独立单位、评价器），不整段复制本手册。
- 文中的学习率等数值是起点区间，不是结论；外部方案与本机案例的成绩只适用于各自的数据与预算。
- 推荐库的许可是 2026-10-22 按 GitHub 元数据核对的快照，引入前以当时的仓库为准。
