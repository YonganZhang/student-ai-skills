# 智慧大屏：源码复用与联动验收

适用：为自有网页制作运营大屏、三维园区/社区看板，或定制已有 Base。已有项目的小修改只执行受影响步骤。本流程提供复用配方，不安装额外技能，不替代项目已有设计总控。

## 1. 选已有骨架

- 先读目标项目的 AGENTS、README、依赖、来源与未提交修改。如有长期记忆工具（可选，本包未包含），查用户已选的智慧大屏模板偏好，定位已选核心、已认可 Base 和视觉参考，再核对磁盘与版本；记忆只提供导航，实际可用性以当前文件为准。
- 已选骨架满足任务时直接复用，在明确目标目录定制，保留原核心和许可。优先从已验证的最小 Base 派生；工程、包或远端地址缺失时按现有交付渠道恢复，仍不可用再说明缺口，按 `dev-find-wheels` 查替代，主栈切换交用户选择。
- 区分可运行源码、编辑器配置/模板、图片参考。核对仓库、不可变 commit、许可、安装与构建；仅截图或配置不作为源码骨架交付。已有来源记录够用就更新，不重复建台账。
- 一个页面选一个主骨架；图表、三维、布局或编辑器按真实缺口组合，先验证接口和依赖。多个候选分别保留职责，不整套混装。用户未要求编辑器时直接做网页。

完成：明确目标工程、来源版本、可复用范围和实际缺口，能启动选中的源码。

## 2. 适配数据与对象

- 先定义对象 ID、区域/层级、时间范围、单位、指标口径、事件状态和允许操作。演示数据一个真源，筛选、卡片、曲线、列表与导出由同一模型派生。环境等指标写明平均或加权口径。
- 校验总量与分项、在线与总设备、已完成与总任务、类别与总数、时间分桶与总能耗等关系。无可加意义的读数不强行求和；没有真实历史时，对比数据标明演示来源，不把固定百分比伪装成计算结果。
- 真实数据接入时校验 schema、唯一 ID、引用关系、枚举、单位、有限数值、计数整数、取值范围及时间格式。明确快照时间与刷新时间；失败保留最后成功数据并显示异常/旧数据，首次失败的示例占位单独标注。
- 演示态可用本地状态实现流程；只读快照只允许读取。前端配置和静态资产不存服务密钥。真实写操作需另有后端契约、授权及失败反馈；本地处理状态不能覆盖真实接口状态或跨数据源串用。
- 三维对象必须与业务 ID 映射；替换对象数量、位置或类型时同时适配模型、拾取与标记，不能只换 JSON。固定示意几何只按已映射对象展示和声称能力。

完成：数据模式和来源可见，关键指标可核对，区域与单对象筛选能得到一致结果。

## 3. 适配视觉与交互

- 从用户已认可的风格开始；新任务无明确风格时读取 Memory 中适用偏好。科技感通过空间层次、材质、灯光和克制动效表达，保持文字、单位、坐标轴和异常状态可读；配色由项目主题集中维护。
- 大屏布局与三维场景分开适配，通过对象 ID、选中范围、事件级别和统一时间连接。按任务实现区域筛选、对象选择、清除选择、事件详情/处理、重置、导出；有动作的控件必须改变可检查的结果。
- 三维用真实渲染场景；设置合理像素比与帧率，考虑减少动态效果偏好、暂停/复位、窗口缩放和资源销毁。页面离开时清理 renderer、材质、几何、事件监听、timer 与动画循环。
- 固定比例缩放与响应式重排分别声明。按目标分辨率检查留白、遮挡、文字和点击定位；缩放后等布局稳定再截图。弹层支持关闭、Escape、焦点返回与键盘访问。
- 接口空数据、加载、异常和恢复路径应可辨认；状态变化由文字/图标共同表达。导出应反映当前范围，说明格式是否支持重新导入。

完成：核心路径可实际操作，三维选择与卡片/列表/标记一致，视觉满足已选风格。

## 4. 验证与交付

- 运行项目约定的安装、类型检查和生产构建。对汇总/筛选/守恒和接口校验做必要的数据契约测试；普通配色或文字修改不补镜像式测试。
- 用 `web-playwright` 实际完成用户路径：区域 → 三维对象拾取 → 清除 → 事件详情/合法状态迁移 → 刷新后的状态 → 重置 → 导出并读取文件核对。仅列表选中不能证明三维拾取已通过；只验页面打开不算交互完成。
- 覆盖目标尺寸（例如固定比例页面的 1920×1080 与 1280×720）、控制台与网络异常。接入接口时用受控响应检查成功、空数据、失败保留、恢复、只读边界；模拟响应和真实后端联调分开报告。
- 对应页面功能缺省时跳过不适用路径，并说明范围。构建通过不能推断长时间运行、移动端重排、多浏览器、大规模数据或真实后台已验收。
- 保留许可、锁文件、来源和修改入口；交付源码包时带上包外测试依赖，独立解压安装验证。静态包实际能通过 HTTP 预览；源码、静态包和证据标明同一版本，生产包不混入私有配置。
- 预览按现有文件交付/浏览器渠道给用户；本机回环地址不能当作用户电脑直接可访问链接。用户要试用时留命名会话并说明有效范围，公开发布另按已有授权执行。
- 项目证据留项目，已认可的模板入口与偏好记入项目文档或长期记忆工具；技能只保留通用工作方法，不硬编码某园区数据、端口或运行状态。

完成：结果、可操作预览/交付文件、通过项、未验范围均有证据；下一次能从来源和修改入口继续定制。

## 与数字孪生的边界

大屏负责运行状态呈现；三维负责空间表达。机理模型、输入/输出、参数有效范围、单位、时间步与重放、守恒关系、校准数据和模型适用性需要按具体领域建立合同和验证。要求流程循环、宏微观联动或参数驱动时，先明确相应状态与模型如何计算，再接入统一时间和对象 ID。没有这些证据时称三维运营演示或示意场景；完成大屏配方不表示具备任意行业数字孪生能力。
