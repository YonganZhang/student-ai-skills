# Phase 2: 分类（Classify）

## 输入
- Phase 1 生成的盘点报告（用户已确认）

## 分类标签

对用户未排除的每个外部 skill，标记为以下之一：

| 标签 | 含义 | 条件 |
|------|------|------|
| **merge** | 合并到现有 skill | 场景与某个现有 skill 重叠 |
| **create** | 新建 skill | 现有体系未覆盖的有价值领域 |
| **split** | 拆分后分别合入 | 一个外部 skill 覆盖多个现有 skill 的场景 |
| **reject** | 拒绝 | 与用户研究方向无关 / 质量不足 / 内容过时 |

## 步骤

### 2.1 逐条分类
对每个外部 skill：
1. 读取其完整内容
2. 提取核心场景（这个 skill 解决什么问题？）
3. 与现有 skill 的场景列表做语义匹配
4. 标记分类标签 + 理由

### 2.2 生成分类报告
展示给用户确认：

```
## 分类结果

### 合并（merge）— {n} 个
| # | 外部 Skill | 核心场景 | → 合并到 | 理由 |
|---|------------|----------|---------|------|
| 1 | model-interpretability | SHAP/LIME 分析 | my-sci-plot | 可解释性绘图与现有绘图 skill 互补 |

### 新建（create）— {n} 个
| # | 外部 Skill | 核心场景 | 建议命名 | 理由 |
|---|------------|----------|---------|------|
| 1 | bayesian-methods | 贝叶斯统计建模 | my-bayesian | 现有体系无此领域 |

### 拆分（split）— {n} 个
| # | 外部 Skill | 拆分方案 |
|---|------------|----------|
| 1 | data-analysis | 统计部分 → my-sci-plot, 写作部分 → my-sci-write |

### 拒绝（reject）— {n} 个
| # | 外部 Skill | 原因 |
|---|------------|------|
| 1 | drug-discovery | 与用户研究方向无关 |
```

### 2.3 用户逐条确认
- 用户可修改任何分类标签
- 用户可将 reject 改为 merge/create
- 所有标签确认后进入 Phase 3

## 门控
用户确认全部分类标签后，进入 Phase 3。
