# 方法框架图（接线图）

“方法框架图”强调组成，“计算流程图”强调计算次序；“接线图”可作讲清模块输入/输出及接入位置的直观叫法。它不是一种新的科学模型。介绍、设计或优化方法，需要讲清输入、模块、输出或接入关系时默认用这类原生图；单点释义、进度询问或不改变方法关系的小修改不强制成图。进度由Plan维护，正式论文图另按科研候选合同。

用户常用入口是“思维导图”，也包括“方法思维导图”“技术流程图”。只要语境在讲方法步骤或模型接入，就按本页图式交付，不要求说“按全局规范”。画法按真实关系组织；知识主题树不凭空增加计算箭头，可交互HTML请求仍走论文/内容导图分支。

## 默认图式

白底、深色文字、少量角色配色、短节点、正交连线。常见总图约4—6个核心节点；模块较多时分总图/详图，不能删掉关键机制凑数量。单链、并行支路、反馈或原方法对照按真实关系选择，不强制所有项目有两条支路。

- 节点写输入、计算或输出的短名称，通常不超过两行；长式子、参数和批次证据留正文。
- 实线表示已定义的计算关系，**不代表已实现、已运行或已验证**。
- 待确定的接入用虚线并说清待标定/待定义什么；参考/约束关系单独标为参考，不能画成实际数据流。
- 核心/继承、扩展、参照与待定节点用角色色区分，颜色不表示当前完成状态。图例同时用线型/文字解释，黑白仍可读。
- 共享输入从一处接出；经验子模型可以在有依据时绕过不需要的中间层。旁支参照没有自动通向最终总分的箭头。
- 每条边写“传什么”。部件状态、损失金额、标准化指标、概率/频率、实际服务量等不靠箭头悄悄换单位。

新SCI入稿图如已安装 `share-sci-plot`（可选，本包未包含），读其科研候选合同；普通方法沟通先交一张清楚的总图，不为模板让用户额外选多版。

## 工具

通用入口`~/.claude/skills/share-technical-roadmap/scripts/method_diagram.py`。图规格的label/位置是方法正文的解释摘要；`sources`指向权威方法和相关实现。规格不保存Plan状态，也不成为新公式真源。

1. 读完方法，参考[中性规格模板](../assets/method-framework.json)另存到项目图源目录，修改标题、真实模块/连线、来源；布局示例不是方法假设。已有批准的draw.io可直接编辑，不强制迁为JSON。
2. 运行构建，输出目录需为空，避免覆盖用户图或历史证据：

```bash
python3 ~/.claude/skills/share-technical-roadmap/scripts/method_diagram.py build --project . --spec path/to/method.json --out-dir _figures/method-r1
python3 ~/.claude/skills/share-technical-roadmap/scripts/method_diagram.py render --diagram _figures/method-r1/diagram.drawio --cache-dir _tmp/method-render
python3 ~/.claude/skills/share-technical-roadmap/scripts/method_diagram.py check --project . --manifest _figures/method-r1/manifest.json
```

构建只用Python标准库，并调用原生结构验证器；只向指定项目内的空输出目录写入。渲染复用已有Playwright/Chromium，以固定hash的官方mxGraph包导出PNG/SVG，不安装全局依赖或把图内容上传网页。环境缺失时如实交代，改用可用的draw.io官方导出；不能拿只有XML当作已看过预览。多页图按既有工具导出PDF，通用模板只生成一页。

命令执行结果在stdout输出JSON；运行错误另在stderr给诊断，参数解析错误沿用argparse的stderr提示。0为成功/记录相符，1为文件漂移或运行/环境失败，2为无效参数或清单结构错误。构建/渲染退出0只证明工具执行，不证明方法正确。

`check`核对规格/指定来源和产物hash，要求完整的图源清单，`rendered=true`还必须登记PNG/SVG；缺项拒绝通过，未登记的渲染半成品会报错。渲染先生成临时文件，发布失败时清理本次新建图像并保留原清单；不承诺多写者事务或强制终止进程时的崩溃恢复。每个调用使用独立版本目录，残留半成品必须先人工复核。render本身不复核来源正文是否漂移，交付前必须运行check。来源更新后先核图语义，再生成新版本；不以重盖hash代替方法复核。脚本不会后台监测、改写正文或更新Plan。

## 人工验收与交付

按[验收合同](acceptance.md)看真实PNG：没有遮挡、穿框、箭头被标签盖住或裁切；缩到最终阅读尺寸仍能看懂。结构验证器不检查科学含义或字体溢出。

至少交`.drawio`与PNG，SVG便于缩放。源图、生成规格/脚本按项目版本管理；重算预览按项目输出规则保存，不为了忽略规则把全部运行依赖入库。保留批准版，不把草案改画成已运行的事实。方法正文/代码变更的同步时机见`project-top`的[方法论工作流](../../share-top/references/methodology-workflow.md)。
