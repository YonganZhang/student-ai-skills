# COL3 · Tests

## Owns

Test gate map, coverage model, reproducible commands, acceptance evidence.

## Anti-owner

- vague prose saying tests exist
- business roadmap
- code registry

## Paths

- `_wiki-methodology/_tests/`
- project test directories such as `tests/`, `_tests/`

## Update When

- new feature requires acceptance gate
- tests change
- evidence is produced
- release/live validation changes

## Verify

- commands are copy-runnable from project root
- dangerous/destructive tests are isolated
- complex projects map change type to required gate
