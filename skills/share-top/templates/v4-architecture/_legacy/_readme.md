# _legacy/ — 旧物归档

> Git：归档时已追踪的保持追踪；新放入的旧物按来源判断（写出来的追踪，能重算的产物不追踪）。

## 放什么

项目里退役的旧代码、旧数据、旧输出、旧流程，按 `_legacy/<名字>-<YYYY-MM-DD>/` 存放。

## 不放什么

- 还在运行的代码 → `_code/`、`_pipelines/`。
- 机器缓存（`__pycache__`、编译产物）→ 直接删，不归档。

## 入口

每个归档子目录带一份短说明：来源、归档原因、恢复方式。

## 文件角色

用户文件先移到这里，不直接删；归档前确认没有仍在用它的地方。

## 改动原因去哪查

`python3 ~/.claude/skills/share-top/scripts/sixone-cli.py record for-file <文件>`，或 `git log -- <文件>`。
