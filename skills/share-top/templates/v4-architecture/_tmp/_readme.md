# _tmp/ — 临时区

> Git：整个目录不追踪（本说明也只留在本地）。

## 放什么

临时下载、上传中转、大文件中转、不需长期保留的中间产物。建议文件名带日期前缀（`<YYYY-MM-DD>_<主题>_<原名>`）。

## 不放什么

- 要长期保留的东西 → 移到 `_data/`、`_refs/`、`_outputs/` 等正式目录。
- 写出来的代码和文字 → 放会被 Git 追踪的目录，不放这里。

## 入口

无；按日期前缀找。

## 文件角色

放久了没用的由用户决定移走或删除。

## 改动原因去哪查

`python3 ~/.claude/skills/share-top/scripts/sixone-cli.py record for-file <文件>`，或 `git log -- <文件>`。
