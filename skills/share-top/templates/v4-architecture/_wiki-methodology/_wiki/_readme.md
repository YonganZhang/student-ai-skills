# _wiki-methodology/_wiki/ - COL1 knowledge

Put stable project knowledge here: methodology, entities, source notes, reusable concepts and design rationale.

Do not put current next actions or active bug queues here; those belong in `_wiki-methodology/_top/_task_plan.md` and `_meta/_known_issues.md`.

## Layout

- `_sources/` — raw material, AI reads but does not rewrite.
- `_entities/` — one file per concept, AI-written and AI-maintained, Wikipedia-style.
- `_index.md` — one-line catalog of every entity, grouped by category. Search here first.
- `_log.md` — append-only log of ingest/query/lint activity.

Full ingest/query/lint workflow and file formats: `references/wiki-writing-method.md`.
